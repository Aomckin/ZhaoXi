# Third-party design provenance

This package was designed after a read-only review of these MIT-licensed
projects, cloned under the workspace `tools` directory:

- FormPilot, Copyright its contributors — scanner, platform adapter, filler and
  orchestrator separation informed this package's module boundaries.
- ResumeBridge, Copyright its contributors — Chinese recruitment field aliases,
  local-first mapping, AI privacy posture and safety classifications informed
  this package's behavior.

The new package keeps its own implementation and does not modify either source
repository. Preserve the upstream license files when redistributing upstream
code or substantial copied portions.
