# Zhaoxi v1.1 发布说明

运行时版本：1.1.0。分支：v1.1。LifeHUD-Tool 保持 1.0.0。

## 本次功能

- 登录常驻：当前用户任务计划程序，登录延迟 8 秒直接运行项目 venv pythonw，后台模式初始隐藏；无管理员要求、无周期重启。
- 单实例：取得实例所有权后再初始化 Core；手动重复启动仅唤起已有窗口。
- 快捷键：默认 Ctrl+Alt+小键盘 0，支持 numpad0～9；窗口可见时隐藏，隐藏/最小化时恢复，冲突不阻断托盘常驻。
- 双击入口：生成“启动朝汐.lnk”，无需打开终端；搬移项目后重新生成。
- 回复显示：按空行拆为气泡，代码围栏内不拆；第一段立即显示，后续随机间隔 5～10 秒；历史恢复无延迟。
- 输入合并：连续发送在最后一条之后等待 2 秒合并；回复期间可继续输入并排队，避免重叠请求。
- 图片：选择或粘贴 PNG/JPEG/WebP，发送前可预览和移除，支持纯图片及图文。保护性上限每次合并请求 20 张、每张 100 MB。
- 图片以多模态内容块传给模型，随本地会话保存。文字模型不保证支持识图，服务商可能施加独立限制。
- 本次一并保留提交用户原有 context、人设 YAML 及角色设定文档，不改写这些已有改动。

## 使用与升级

现有环境退出朝汐后双击启动入口，加载新代码。登录常驻安装、查询和移除见 [常驻说明](presence-autostart.md)。旧 Session 文本记录可继续读取，不要求删除用户数据。

自启动任务和快捷方式使用本机路径；项目移动或 venv 重建后重新生成。`.env`、`.zhaoxi` 数据及本机快捷方式不进入 Git。
