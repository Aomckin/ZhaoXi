# Zhaoxi v1.4.5 · Dashboard & Control Plane

2026-10-03，本版源码开发与隔离验收完成。正式桌面实例尚未重启加载；真实 QQ 收发与长期使用观察仍待进行。

## 入口

普通浏览器访问 `http://127.0.0.1:4913/`（或配置的本机端口），自动进入 `/dashboard`，无需 `ZHAOXI_DEV_BROWSER_UI`。小桌边底部 **打开管理面板** 和桌面托盘 **设置** 均通过默认浏览器打开，聊天窗口保持原页面。管理页顶部 **打开朝汐桌面** 可唤起桌面主窗口。主页面继续提供对话、Presence / 当前活动、留言、日程与近期认知摘要；工程检查和管理控件已移出。

Dashboard 分为概览、生活状态、内部活动、近期认知、记忆、运行观测、能力与社交、设置。工程工具通过独立页面按需加载，四页共 28 个折叠项支持点击展开与收起。

管理页自动建立独立的 HttpOnly / SameSite=Strict 本机浏览器会话，无需桌面启动令牌。该会话的页面与 API 请求校验回环地址、Host、Origin 和 Fetch Metadata；工程 iframe 复用管理会话，生活页面保留桌面会话。

## 看得懂结果

- 手动活动点击后立即显示执行中状态，完成后显示中文回执、变化、耗时、外部发言与失败阶段；原始结果折叠于技术详情。
- 自动活动与手动活动保存统一历史，保留最近 200 条并支持分页；主页面短暂显示自动活动的最近结果。
- 回执由结构化结果生成，不追加模型解释调用。Gardening 提供修改列表；失败、无变化、跳过、拒绝和前台让路均有明确反馈。

## 调得动行为

- ACTIVE / SEMI_ACTIVE 驻留时间、Heartbeat 总开关、基础间隔与五态倍率可持久化调整；支持自动睡眠时间设置。
- 展示进入时间、持续时间、下一状态、预计切换与 Heartbeat 状态。前台任务进行时保持 ACTIVE，结束后开始驻留窗口。
- 强制五态期间暂停自动切换；恢复自动重新计算窗口。快速切换测试使用 **DEBUG OVERRIDE**：10 秒 ACTIVE、20 秒 SEMI_ACTIVE、5 秒 Heartbeat，一键退出且不持久化。
- 活动按五态设置自动 / 仅手动 / 禁用，并可调整启用、优先级、最短间隔与每日预算；总开关、Tick 资源预算和每日资源预算均可调。
- 社交开关、授权群、群冷却及每日发言限额集中在能力与社交页。Social Wander 默认关闭，手动发言要求本次确认，继续检查白名单、隐私、来源和预算。

## 纠正近期认知

- 编辑概览或恢复自动维护；新增、编辑、置顶、锁定、合并、淡出、解决或删除主线；管理近期变化与留意事项。
- 人工条目保存 OWNER_MANUAL 元数据。置顶条目不会自动淡出，锁定正文不会被 Maintainer 或 Gardening 覆盖。
- 解决与删除退出活跃集合并保留历史；同 key 或近似文本的旧证据在 7 天内受到抑制。对有证据的条目，新证据可以重新形成主线。
- 手工修改与修订日志在同一事务保存；可以撤销最近一次人工修改。撤销只恢复受影响条目，保留其他后台变化；目标已有新修改时拒绝覆盖并提示人工核对。

## 生效与存储

Dashboard 参数优先于启动时的 `.env` / 代码默认值；临时 DEBUG OVERRIDE 优先于持久配置。

- 参数：与 `internal_activity_db_path` 同目录的 `<数据库名>-settings.json`，默认 `.zhaoxi/internal-activity-settings.json`。原子保存并纳入备份注册表。
- 活动回执：现有内部活动数据库新增 `activity_history` 表。
- 人工认知与抑制记录：现有 Current Cognition 状态；修订记录新增 `cognition_revisions` 表。

Presence 参数立即重新计算，Heartbeat 保存后重排等待时间，活动参数在下次候选检查生效。恢复默认读取当前启动配置。预算用量采用执行前保守预留；失败或不确定外部发送不自动退回预算，不等同于精确 Token 账单。

旧数据库自动添加独立表与模型默认字段，无需离线 Memory 迁移。更新后需退出并重新启动整个朝汐桌面进程，再刷新管理页；单独重建 Agent 的“重启 Core”不会重新加载已导入的 Python 模块。已有会话与数据库保留。
