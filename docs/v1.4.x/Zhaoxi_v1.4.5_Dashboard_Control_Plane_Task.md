# Zhaoxi v1.4.5 · Dashboard & Control Plane

本版完整需求以 [中文开发任务书](Zhaoxi_v1.4.5_Dashboard_Control_Plane_开发任务书.md) 为准。

交付主线为 Observe / Control / Correct：独立 Dashboard、确定性操作回执、持久化 Presence / Activity 控制，以及带人工状态、修订与撤销的 Current Cognition 编辑器。复用现有 Scheduler、Memory、Planner 和社交安全机制。

实现、验证与尚未进行的正式实例验收见 [开发记录](Zhaoxi_v1.4.5_开发记录.md)；入口与使用方式见 [版本说明](Zhaoxi_v1.4.5_Release_Notes.md)。
