## 版本变化

旧检索将重要性、热度和相关性混在一起，并依赖宽泛 topic bucket。现在 importance、activation、contextual_relevance 分别管理；自然联想、明确回忆和广泛搜索采用不同状态与簇限制，冷记忆需满足更高关联门槛，已遗忘或被替代的记录不进入正常召回。

- 检索与分簇：簇优先搜索结合有界 SQLite FTS、语义、实体及近期逃逸候选；语义分簇保留孤立记忆，summary 参与合并，明确回忆按最佳簇置信度与领先幅度放宽。
- 语义接入：版本化 Embedding 配置与兼容性检查，百炼 `text-embedding-v4` / version `1` / 1024 维已启用；不混用不同向量空间，接口失败时走词法检索并记录错误。
- 后台记忆：有界结构化提取、可信输入证据、显式记住控制；维护队列持久化阶段名，阶段独立失败，外部 Owner 消息合批并按优先级调度，去重及前台让路。网关忽略关闭思考时，AutoMemory 使用最多 6000 token 的有限额外预留；正文与候选上限仍有效。
- 上下文与调试：只注入选中的记忆；书库元数据提供文档引用线索，正文走工具读取。Inspector 展示三模式、写入原因、证据、热度历史、簇与排除轨迹，支持指定记忆 ID 诊断。
- 存储与维护：离线审计、预演、备份、取消、发布和回滚；兼容快照按内容 hash 复用向量，不覆盖原库新增记录；图片共享内容寻址 blob，数据库可执行离线 VACUUM。

## 原库迁移及启用

用户退出桌面后，17 个数据库备份均通过 SHA-256 与完整性校验，记忆备份在隔离路径恢复后 1029 条 ID、正文和状态一致。原记忆库迁移已发布：1029 条记录、1024 条有效语义向量、最大簇 80；五条 FORGOTTEN 排除，1020 条向量复用兼容快照。真实质量对照采用此前冻结的 1025 条副本，不将原库新增四条混入基线。

Experience / Perception / Session 的历史图片迁入共享 blob 并完成 VACUUM，数据库分别从 198422528 / 146292736 / 61145088 字节缩至 3039232 / 2764800 / 102400 字节，freelist 均为零；共享媒体占用独立保留，不能按数据库差值宣称总磁盘净节省。

本机 editable 安装已更新。正常网络权限下重启桌面，health 返回 `1.4.3`，三种召回模式的百炼向量均 available。复测仅使用只读 API，不发送聊天或外部消息。
