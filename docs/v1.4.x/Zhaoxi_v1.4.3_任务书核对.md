## 真实质量审查

对冻结的 1025 条真实记忆副本、十个查询、K=6，按相同查询准则复核迁移前后 Top-K 的合并结果池；共 94 条判断。旧基线提交为 `937ae4481de7db3bcca1f4d90d77d69d8ba62914`。新增验收脚本使用冻结旧结果、缓存百炼查询向量和快照，避免运行中原库新增四条记录改变比较基线；门槛失败返回非零退出码。

| 口径 | 指标 | 迁移前 | 当前实现 |
| --- | --- | ---: | ---: |
| 原固定 ID（未修改） | Recall@6 | 0.8000 | 0.8250 |
| 原固定 ID（未修改） | Precision@6 | 0.2833 | 0.3000 |
| 原固定 ID（未修改） | MRR | 0.9000 | 0.8250 |
| 内容复核结果池 | Recall@6 | 0.6207 | 0.7231 |
| 内容复核结果池 | Precision@6 | 0.5667 | 0.6833 |
| 内容复核结果池 | MRR | 1.0000 | 1.0000 |
| 内容复核结果池 | 每查询拒绝噪声命中 | 2.6 | 1.0 |

原 MRR 的下降来自 QQ 接入查询，原标签遗漏了排在前面的相关接入原则与状态；本次未给固定 ID 特判或调权。两种口径同时保留。复核结果池不是全库穷尽 gold，Recall 仅针对该池；复核者为 Codex 开发代理，**不是独立人工或用户验收**。“拒绝噪声”指按查询准则判定的无关内容，不是已遗忘状态；真实桌面三模式未返回 FORGOTTEN / SUPERSEDED 记录。
