# 行动记录：Token 用量与过程正文

日期：2026-10-12。本补丁基线：`7e4f858`，沿用源码版本 1.4.9。

## 行为

- 行动记录显示每次真实模型请求的编号、模型、所属阶段、输入/输出/合计 Token、耗时与结果；重试按独立请求计入。
- 顶部汇总本次请求的消耗；仅汇总实际返回的 usage。API 未返回用量的调用显示“未返回”，部分已知总量明确标为“已知”，不把缺失算作 0。真正返回的 0 保留。
- API 没有 total_tokens，但同时返回输入与输出时，合计取二者之和。200 响应在工具参数解析阶段失败时，已经返回的 usage 仍被记录。
- 根据用户确认，展示非最终调用返回的正文/规划说明，默认折叠，可展开阅读全文；不读取 reasoning_content，不生成新的思考说明，也不增加模型调用。
- 最终回复的调用仍计入用量，正文只在聊天区交付。FAST 升级、回复校验等已拒绝草稿不进入事件或公开指标，仅保留调用用量及“草稿未采用”状态。
- 过程正文确认是中间结果后才发布；未确认正文保存在请求内部，不进入 SSE、日志事件或 Debug 快照。请求结束后的关联后台调用继续更新该请求的统计。
- 桌面与 Dashboard 共用原有事件和快照；中途刷新、重新进入运行观测及重复事件不会重复累计。

## 实现

`ResilientProvider` 在真实请求开始时分配稳定编号，ContextVar 隔离并发请求的用量；OpenAI 兼容入口在解析工具前保留 usage。`ActionTrace` 聚合用量，并区分中间正文、最终正文和未采用草稿。Agent、FAST 与 Planner 在最终回复被接受时标记对应调用。前端按调用编号更新卡片，用 textContent 呈现正文，不作为 HTML 执行，也不写入聊天历史。

不新增依赖，不改变预算额度、模型选择或工具执行策略。私人数据忽略规则保持有效。
