# v1.4.9 · 行动后上下文精简、图片释放与工具预挂载

日期：2026-10-13（Asia/Shanghai）。V149-08—V149-11 源码及隔离验收完成，任务范围见 [任务书](../v1.4.x/Zhaoxi_v1.4.9_代码精简_开发任务书.md)。

## 实现

成功业务结果之后，普通 Agent 下一轮去掉完整能力目录、领域行动提示、无关强制工具和桌面活动/驻留上下文，缩短中间台词提示；保留人格、回复契约、原请求、相关时间线、事实回执及续办所需工具。模型可直接给最终回复，也可继续原请求中的剩余动作。未修复的失败或部分成功不进入成功精简路径。权限续跑复用原请求状态与结果；Planner 完成计划的收尾取消领域行动提示且不发送工具定义。

ToolExecutor 根据本次实际权限与非空、未截断的成功结构化结果产生 confirmed_write；只读查询和缺少结果数据不标记。该回执作为当前图片事实已落入结果的释放判据：后续上下文和补回复将当前附件、引用图片改为最大边长 512px 的缩略图，同时保留真实结果及摘要；缩略图失败不回填原图。Conversation、原附件和原图工具引用不被修改。Planner 同样沿用当前 Goal 的已确认观察结果。

每个实际 Provider 尝试记录 System / Persona / Tool Schemas / Timeline / Tool Results / Images / Memory / Cognition 的字符数及文本估算；未分类的系统附加提示计入 System。八类字符数覆盖实际请求，图片载荷从 Timeline 中扣除。诊断只包含长度、数量和用量，不含正文、原图或隐藏思考。通过调用 ContextVar 对齐重试/补回复，不依赖最近一轮全局记录。行动记录逐次及累计展示，SSE、最终快照、刷新恢复和重复事件均复用原调用编号。API 的实际输入/输出/合计仍独立展示；文本分项按字符÷4粗估，Images 报告张次和载荷字符，有 prompt_tokens_details/input_tokens_details.image_tokens 时显示报告值，否则未知。

CognitiveRouter 已有实时 Tool Domain Map，本补丁增加同次 route_cognition 的 preload_tool_groups，最多四个组。Agent 首轮挂载有效、启用且可用的工具，预测与实际挂载留在原诊断中。预挂载不消费原按需发现的两次扩展额度，不额外执行工具，不改变确认规则；当前请求结束后清空。撤销强制暴露不会取消已预测挂载，停用仍立即过滤。FAST、图片直达及本地明确路径继续原确定性路由，不新增预测模型请求；Planner 业务轮已有全部工具定义，本补丁仅精简其收尾。
