# Desktop 图片查看与消息右键交互

用户要求：Desktop 中点击图片放大查看，消息右键可以引用或复制。

## 实现

- 主聊天、历史图片、表情图片、待发送图片使用窗口内 modal 查看器，不打开浏览器新窗口。支持滚轮 / 按钮缩放、拖动、适应窗口、原始大小、关闭按钮和 Esc；图片可用 Enter / 空格打开。
- 消息右键菜单提供引用消息、复制文字；含图片时提供复制图片。复制取消息原文，不带时间标签、朗读按钮等界面文本；图片复制为保留尺寸的 PNG，兼容 JPEG / WebP 来源。
- 引用把发送者、已有时间、原文放入输入区，可继续编辑；图片引用同时附上原图。沿用原有 20 张图片 / 20000 字及连续输入合并限制，不新增模型请求或后端会话。
- 菜单支持 Shift+F10、方向键、Esc、点击外部关闭。文字剪贴板 API 不可用时回退系统复制；失败时明确提示，不假报成功。
- 陪伴模式沿用同一消息投影，补上图片缩略图和相同查看 / 右键操作。主窗口与工程页面共同加载交互模块。
